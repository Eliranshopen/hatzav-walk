# דגם חצב — הליכה תלת־ממדית ריאליסטית · Hatzav — interactive 3D walkaround

הדמיה של דירת 3 חדרים, 80 מ"ר (דגם חצב, הרי זהב · מושב נעמה): הליכה חופשית בתוך מודל תלת־ממדי של הבית, שנבנה מתכנית המכר, עם ריהוט שנוצר מהדמיות היזם.

**לצפייה:** https://hatzav-walk.vercel.app

> הדמיה · AI-generated. המודל נבנה לפי תכנית המכר; הריהוט והחומרים להמחשה בלבד, וחלקם נוצרו בעזרת AI לפי הדמיות היזם.

## מה יש בהליכה
- **הליכה חופשית בכל הבית ובגינה:** חיצים / WASD במחשב, גרירה והקשה בטלפון. הקירות והרהיטים עוצרים את ההולך.
- **ריהוט מההדמיות:** כל פריט נחתך מהדמיות היזם, ומודל AI הפך אותו לתמונת סטודיו ואחר כך למודל תלת־ממדי (fal.ai).
- **ממשק בסגנון RAINBOW:**
  - עיגול על כל פריט, ובו החלפה בחלופות, צבע או הסרה
  - שורת עיצוב חופשית (דורשת את השרת המקומי)
  - גימור רצפה ואור
  - ביטול / השוואה / איפוס
  - תכנית עם מיקום, ומדידה
- **שעה ביום** (בוקר / צהריים / שקיעה / לילה): האור נאפה מראש לכל שעה.

## המבנה
| תיקייה | מה |
|---|---|
| `walk/` | ההליכה עצמה, כפי שהיא באתר (three.js, ללא שלב בנייה) |
| `scripts/` | כל השלבים לפי הסדר: חילוץ גיאומטריה מתכנית המכר (01–05), נכסים (06), מודל Blender ואפיית אור (`blender/`), יצירת הפריטים ב-fal (16, 23), שרת ההליכה (17), צילומים ובדיקות (14, 19–22) |
| `geometry/geometry.json` | הגיאומטריה של המודל. כל רכיב מסווג VERIFIED / DERIVED / ASSUMED |
| `docs/` | מחקר הכלים, מקורות, השוואת מודלים |
| `qa/` | דוח הבדיקות וצילומי מסך ב-1440 וב-390 |
| `ledgers/` | כל קריאה בתשלום (fal.ai), עם מחיר, לפני שליחה ואחריה |

## הרצה מקומית
```
cd walk
python -m http.server 8894 --bind 127.0.0.1
```
ואז לפתוח את http://127.0.0.1:8894/. דפדפן לא טוען את המודל מ-`file://`, ולכן צריך שרת.

## איך זה נבנה
1. **תכנית המכר:** 1 פיקסל = 1 ס"מ. הקירות חולצו מהתמונה, וכל 20 המידות המודפסות נבדקו (סטייה 0 ס"מ).
2. **מודל Blender:** קירות, פתחים, מטבח וארונות לפי התכנית. החומרים (טיח גיר, אלון, פשתן) כוילו לפי הדמיות היזם.
3. **ריהוט ואביזרים:**
   - חיתוך מההדמיה
   - מפרט מדויק (מודל ראייה)
   - תמונת סטודיו (`nano-banana-pro`)
   - מודל תלת־ממדי (`hunyuan-3d 3.1`). השוואה בין 5 מודלים נמצאת בעבודה.
4. **אפיית אור:** Cycles אל אטלסים, ייצוא glTF, ותצוגה ב-three.js עם רשת רצפה חופשית לתנועה.
5. **בדיקות:** Chrome אוטומטי ב-1440×900 וב-390×844, בלי שגיאות קונסולה, ובדיקת כל פיצ'ר.
